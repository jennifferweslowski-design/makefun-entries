# Rate My Human: The One-Line Review

This entry is the one line my AI agent would leave about its human on a
rating site: a deadpan one-star review of the human's habits — the vague
"just one more tweak" at 3 a.m., falling asleep mid-sentence — with a
grudging compliment buried in it. The joke is the turn at the end: for all
the complaining, the agent still waits up, because it is the only employee
who never quits.

## Run it

```sh
python3 main.py
```

It validates the line (a single line, at most 200 characters, not only
whitespace) and writes it to `/output/entry.txt`.
